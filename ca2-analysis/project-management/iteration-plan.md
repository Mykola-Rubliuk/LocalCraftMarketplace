# Suggested iteration plan

## Iteration 0 — agree the baseline
Scenario confirmation, Product Goal, selected use cases and shared glossary.

## Iteration 1 — agree integration contracts
Freeze StockAvailabilityPort, SaleRecordingPort, Clock, error conventions, fake contract tests and design conventions.

## Iteration 2 — slice design
Each owner validates their use case, Gherkin, SSD, contracts, CRC, GRASP and sequence. Use branches/PRs for coherent changes.

## Iteration 3 — integration and review
Integrate one class diagram, package/layer view, traceability and dossier. Resolve cross-slice issues.

## Iteration 4 — final evidence
Complete peer reviews, AI declarations, contribution statements, walkthrough preparation and final tag.
